### Universal Track System

    src="https://raw.githubusercontent.com/blanksblankss/blanksblankss/main/media/universal_track_system.gif"

**Universal Track System** is a modular Unity timeline and editor framework built around extensible tracks, presets, reusable workflows, and reflection-based property exposure.

It represents the kind of tooling I enjoy building: systems that reduce repetitive work and give designers and developers more control inside the editor.
